# Opening layout · v0.54.0

The setup panel follows this order:

1. Restaurant, with the current reputation in its heading.
2. Ulti, showing the selected grade/team pool; tap to open the existing ledger.
3. Team.
4. Lesson and compact Relaxed/Challenge pace controls.
5. Shop beside Open café.
6. Design at the bottom.

Compact portrait layouts show the complete setup, with controls at least 44 CSS pixels high. The Lesson button keeps a short visible title and its complete accessible name; all units remain available in the lesson dialog. Very short landscape windows scroll inside the setup screen, so controls remain reachable without scrolling the game canvas. Device safe areas retain padding.

Pass & Play is removed from the setup and help. Configuration normalization disables older saved cooperative settings, and successful deliveries no longer change roles. Existing saves, team rewards, reputation, Ulti expiry, language data and task colours are preserved.

The character is called Chef in the opening, results, station help and portrait descriptions. The creator credit remains “by Mr. Saymaz.” Artwork filenames are retained for save and asset compatibility.

Validation results are recorded in BUILD-INFO.json and validation/opening-layout-v0.54.0.json. Browser checks use Chromium software WebGL and emulated touch; physical phone performance is unmeasured.
